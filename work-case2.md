## Набір базових дій в встановленому мною гіпервізорі:
### Створення нової віртуальної машини
Для створення нової віртуальної машини у VirtualBox було виконано такі дії:

1. Запущено програму Oracle VirtualBox.
2. Натиснуто кнопку New (Створити).
3. Введено ім’я віртуальної машини.
4. Обрано тип та версію операційної системи (Linux / Ubuntu).
5. Підтверджено створення віртуальної машини.

У результаті було створено порожню віртуальну машину, готову до подальшого налаштування та встановлення операційної системи.

### Вибір та додавання обладнання для віртуальної машини
Під час створення віртуальної машини було налаштовано основні апаратні ресурси.
Для коректної роботи операційної системи Ubuntu були виділені такі параметри:

**оперативна пам’ять — 4096 МБ;**

**кількість процесорів — 2;**

**віртуальний жорсткий диск типу VDI, динамічного розміру, обсягом 25 ГБ;**

**використано стандартний відеоконтролер VMSVGA.**

<img width="1241" height="644" alt="image" src="https://github.com/user-attachments/assets/b65616e2-a782-48df-a38e-a49176bb217c" />

### Налаштування мережі та підключення до Wi-Fi
Для забезпечення доступу до мережі Інтернет у VirtualBox було використано мережевий режим NAT.
У даному режимі віртуальна машина отримує доступ до мережі через мережеве підключення хост-системи, що дозволяє використовувати Інтернет без додаткових налаштувань Wi-Fi всередині віртуальної машини.

<img width="526" height="145" alt="image" src="https://github.com/user-attachments/assets/01aa24f9-8c85-409a-b07b-546fdb203ba3" />

### Робота з зовнішніми носіями (USB / flash-пам’ять)
Гіпервізор VirtualBox підтримує роботу з зовнішніми USB-носіями.
Для цього у налаштуваннях віртуальної машини використовується розділ USB, де можна підключати flash-накопичувачі безпосередньо до віртуальної машини.
За необхідності можуть бути створені фільтри USB-пристроїв для автоматичного підключення.
